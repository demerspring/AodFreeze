# 傲盾还原

> 磁盘无缝还原系统 —— 类似“影子系统”的轻量级磁盘保护工具。
> 基于已停止维护的 [diskflt 项目](https://code.google.com/p/diskflt)（原作者 dbgger）修改、增强而来。

## 📖 简介

**傲盾还原** 是一款内核级的磁盘还原/影子系统方案，通过模拟硬件还原卡的工作原理，实现对硬盘（分区）的写重定向。所有改动在重启后自动清空，有效保护系统免受病毒、误操作和恶意软件的影响。

- 驱动级实现，稳定且高效
- 单一 `.sys` 文件，全绿色免安装
- 密码保护，输入密码后可自由配置保护策略

## ✨ 主要特性

- **广泛的系统支持**
  - 兼容 Windows XP SP2、Vista、7、8、8.1、10、11。
  - 兼容 x86、x64、ARM64（实验性） 架构

- **全面的分区保护**
  - 仅保护系统盘，或全盘保护（含多硬盘）
  - 支持 MBR 与 GPT 分区表自动保护（受保护盘的分区表不可篡改）
  - 支持保护无盘符的隐藏分区

- **文件系统兼容**
  - 支持 FAT、NTFS 文件系统
  - 大部分代码不依赖于文件系统的实现，易于移植

- **强大的防穿透还原能力**
  - 阻止 Ring3 层绕过还原的常见手段（如 SCSI Passthrough、IOCTL 修改分区表）
  - 集成防“机器狗”模块，可配置第三方驱动拦截策略

- **灵活的驱动控制**
  - 驱动白名单 / 黑名单拦截，允许临时解除或重新启用
  - 当开启白名单时，保护盘上原有的驱动会自动允许加载（仅限系统盘保护）

- **高级空间管理**
  - 解冻空间：创建可持久化的虚拟分区，方便保存数据
  - 直接挂载：支持挂载保护分区进行直接读写
  - 保存数据：在关机时保存保护分区的数据

## ⚙️ 操作说明（快速开始）

1. **准备驱动签名**
   项目不提供正式数字签名证书。请自行使用代码签名工具对驱动文件签名，或在系统启用 `测试模式` 后再加载驱动。

2. **配置保护策略并安装驱动**
   - 运行管理工具（`DiskfltInst.exe`）
   - 选择保护模式：仅系统盘 / 全盘 / 自定义分区
   - 根据需要配置驱动黑白名单、解冻空间等
   - 点击安装驱动，设置密码
   - 提交设置并重启生效

3. **日常使用**
   - 重启后所有非解冻区域的更改均会丢失，系统回到初始状态
   - 可通过缓冲区工具查看缓冲区使用情况
   - 可通过管理工具临时挂载保护分区，进行特定文件的读写（需要预先启用该功能）
   - 可通过管理工具单次保存分区的数据，需要在关机或重启时进行
   - 临时解除驱动拦截或添加例外时，无需重启，但注意安全风险

4. **卸载**
   - 通过管理工具关闭保护，重新启动后再卸载驱动

## ⚠️ 注意事项

1. **驱动签名**
   - 项目未附带任何正式数字证书，**请务必自行对驱动签名，或通过测试模式加载**，否则无法运行。

2. **安装前检查**
   - 确保被保护的硬盘无文件系统错误或硬件故障
   - 保护系统盘前，请确认没有正在进行的 Windows 更新操作，以免引发冲突
   - 暂不支持与 BitLocker 或设备加密同时使用。请**完全关闭**相关功能后再启用本软件

3. **驱动白名单限制**
   - 开启白名单后，只有保护盘上已存在的驱动才会被自动信任
   - **如果不保护系统盘，则不能启用驱动白名单功能**（系统驱动的完整性检测依赖系统盘保护）

4. **缓冲区与挂载风险**
   - 当缓冲区空间不足时，直接挂载并写入保护分区会覆盖已有缓冲区数据，可能导致系统不稳定甚至蓝屏
   - 建议仅在确有必要、且确认缓冲区充裕时使用挂载写入
   - 保存数据为实验性功能，与分区挂载冲突，请谨慎操作，并确保**内存充足**且**不要在关机中途断电**，以免造成数据丢失、文件系统损坏

5. **解冻空间注意事项**
   - 添加解冻空间时，必须指定硬盘上**真实存在且可访问**的文件作为虚拟磁盘文件；若文件不存在，程序可能自动创建，但该文件随后会转为私有用途，不可被其他程序访问
   - 避免将关键系统文件设为解冻空间虚拟磁盘文件，以免引起冲突
